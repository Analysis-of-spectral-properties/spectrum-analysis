# spectrum-analysis
# Анализ спектральных свойств матрицы расстояний для задач многомерного анализа

Научно-исследовательский проект, посвященный изучению спектральных свойств матриц квадратов расстояний в конечномерных и бесконечномерных пространствах. Результаты работы имеют прикладное значение для алгоритмов кластеризации, визуализации данных (MDS) и анализа структурных связей.

---

## Постановка

При анализе многомерных данных информацию часто представляют в виде матрицы квадратов расстояний между элементами ($D^{(2)}$). Непонимание фундаментальных свойств ее спектра приводит к неэффективному использованию матриц в задачах многомерного масштабирования (Multidimensional scaling, MDS) и кластеризации.

### Области применения
* **Биология**: Поиск эволюционных зависимостей (например, между штаммами вирусов).
* **Хемоинформатика**: Эффективное различение молекул разного размера по наибольшему собственному значению матрицы расстояний между атомами.
* **Анализ социальных сетей**: Выявление скрытых сообществ и объединений людей.
* **Экономика и финансы**: Определение главных компонент риска.
* **Материаловедение**: Выявление устойчивых кристаллических структур.

---

## Цели и задачи

**Цель:** Определить основные свойства матрицы квадратов расстояний.

**Задачи:**
1. Проверить гипотезу о соотношении числа отрицательных и положительных собственных значений матрицы квадратов расстояний в конечномерном пространстве.
2. Провести аналогичный анализ для бесконечномерного пространства.
3. Математически обосновать полученные результаты.

---

## Основные результаты

### Теоретические результаты
* **Конечномерные пространства:** Доказано обобщение теоремы Перрона–Фробениуса. В конечномерном пространстве с евклидовой метрикой существует единственное положительное собственное значение, которое по модулю превосходит все остальные ($\exists!\lambda \in \sigma(D) : \lambda = \max_{\mu \in \sigma(D)} \mu, \lambda > 0$). При этом число отрицательных собственных значений ровно на 1 меньше размерности пространства.
* **Бесконечномерные пространства:** Доказана теорема о конечности числа неотрицательных собственных значений через функционал следа экспоненты оператора ($\text{tr} \circ \text{exp}$). Установлено изоморфное вложение множества матриц $HSM_{\mathbb{R}}^+$ в алгебру Калкина ($\mathcal{B}(E)/\mathcal{K}(E)$).
* **Алгебраическая структура:** Нам удалось ввести в множество матриц $HSM_{\mathbb{R}}^+$ структуру векторного пространства над $\mathbb{R}$, переопределив операцию умножения ($A \cdot B \longleftrightarrow A \odot B$). Доказано, что пара $(HSM_{\mathbb{R}}^+, \odot)$ образует коммутативную алгебру.

### Технические и численные результаты
* Описан класс метрик (Манхэттена, Брея-Кёртиса), где выполнение гипотезы зависит от соотношения размерности пространства и числа объектов. Для метрик Минковского при $p > 2$ гипотеза выполняется всегда.
* **Реализован алгоритм cMDS (Classical Multidimensional Scaling)**, который точно восстанавливает исходные точки по матрице расстояний в Евклидовом пространстве. Разработанное решение превосходит по точности и стабильности аналогичные реализации из открытых источников.
